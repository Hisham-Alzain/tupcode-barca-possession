# Metrica Sports Smart Tagging (how it works)

- **Source:** vendor product. **No public method description found** (searched for Metrica Smart Tagging docs; the results returned only Vidal-Codina et al. and unrelated vendors). Local facts come from `third_party/mtah/DATA.md`.
- **Year / venue / URL:** n/a; the tags ship with the challenge match as `BAR-ATH_tactical_smart_tagging.xml`.

## Key facts (local, DATA.md)
- 638 automatic intervals, generated by Metrica from the same video and tracking, **not reviewed by a person**. They contain false positives and false negatives.
- `SET PIECES`: 59. Types: throw-in 26, corner 12, goal kick 10, free kick 5, kick-off after goal 4, kick-off at the start 2.
- `Team` is `N/A` on 36 instances, **including every throw-in**. Corners, goal kicks, free kicks and kick-offs carry a team (about 33 instances).
- Times are seconds of the tactical video; `frame = round(s * 25)`.

## Relevance to us
- About 64 ball-outs per game (SoccerNet rate) against 59 tagged set pieces, and fouls and offsides come on top of those. So tags cover **at most half of the true stoppages**. Use them as anchors, not as the detector.
- For the 33 non-throw-in set pieces, the tag's Team is a direct restart-team prior. Check first that Team means the **restarting** team (DATA.md shows that Team differs by tag type).
- **Cannot be benched**: Metrica Sample Games and IDSSE have no Smart Tagging, so any gain is unmeasured on external data.
